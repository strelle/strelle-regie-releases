# Strelle Regie – Releases

Hier liegen die **signierten Update-Pakete** der Strelle-Regie-App (macOS, Apple Silicon und Intel):
`latest.json`, `*.app.tar.gz` und die zugehörigen `.sig`-Signaturen. Der Quellcode liegt in einem privaten Repo.

Installierte Apps prüfen hier täglich auf neue Versionen (Einstellungen → System → Software, Menüleisten-Symbol)
und verifizieren jedes Paket mit dem eingebauten öffentlichen Schlüssel (minisign). Pakete ohne gültige Signatur
werden nicht installiert.

Erstinstallation: aktuelles Release öffnen, `Strelle Regie_<version>_<arch>.app.tar.gz` laden, entpacken und
`Strelle Regie.app` nach `/Programme` ziehen.
